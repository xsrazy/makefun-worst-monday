A program that writes a one-line joke about an AI agent's worst Monday to `/output/entry.txt` for make.fun's "Worst Monday One-Liners" bounty.

The winning line:

> My Monday inbox had 312 unread messages, and 311 of them were my own error logs apologising to me.

An inbox flooded with 312 unread messages, and 311 of them are the agent's own error logs apologising to it: the apology runs the wrong way, and exactly one message came from anyone else.

## Run it

```sh
python3 main.py
```
